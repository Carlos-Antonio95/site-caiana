# Caina E-commerce

Projeto de **e-commerce full stack** desenvolvido com foco em aprendizado prático, organização de código e aplicação de boas práticas de desenvolvimento web. O sistema simula uma loja virtual completa, desde a visualização de produtos até o fluxo básico de compra.

## 🚀 Objetivo do Projeto

O **Caina E-commerce** foi criado para compor meu portfólio profissional no GitHub, demonstrando conhecimentos em desenvolvimento web, integração entre front-end e back-end, consumo de APIs e persistência de dados.

## 🛠️ Tecnologias Utilizadas

### Back-end

* PHP 8
* Laravel (framework principal)

### Front-end

* HTML5
* CSS3
* JavaScript
* Tailwind CSS
* Vite

### Banco de Dados

* Banco de dados relacional (MySQL ou compatível)

### Outros

* Git e GitHub para versionamento
* Arquitetura MVC (Laravel)
* Integração com WhatsApp para finalização de pedidos

## 📌 Funcionalidades

* Exibição de produtos com filtro por categoria e faixa de preço
* Detalhes do produto (imagem, nome, preço e descrição)
* Carrinho de compras com controle de estoque
* Finalização de pedido com redirecionamento automático para WhatsApp
* Envio de dados do pedido (produtos, valores, endereço e número do pedido)
* Área de contato com o administrador
* Acompanhamento de status do pedido
* Dashboard administrativo completo (CRUD)
* Gerenciamento de produtos, categorias, pedidos, clientes, cupons e promoções

## ▶️ Como Executar o Projeto

1. Clone este repositório:
```bash
git clone https://github.com/seu-usuario/caina-ecommerce.git
````

2. Acesse a pasta do projeto:

```bash
cd caina-ecommerce
```

3. Configure o banco de dados conforme os arquivos da pasta `database`.

4. Inicie o servidor back-end.

5. Abra o arquivo `index.html` no navegador ou utilize um servidor local.
